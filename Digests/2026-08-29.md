# OpenAI 今天一邊放行、一邊收回

> 今天的問題：OpenAI 同一天做出兩個方向相反的模型存取決定，這說明它把存取權當成什麼在用？

OpenAI 與泰國高等教育科學研究創新部（MHESI）合作推出八週加速器，篩選 10 家健康、康養與教育領域的新創，協助它們把 AI 原型做成可信賴的產品。

同一時間，OpenAI 宣布因為 Cursor 遭 SpaceX 收購，決定終止原本提供 OpenAI 模型給 Cursor 使用的合約。

模型 API 供應合約常帶有客戶資格與用途限制條款，客戶所有權結構出現重大變化（例如被併購）時，供應方重新審查合約是業界常見做法，不是 OpenAI 獨有的動作。

把這兩個決定放在一起看，OpenAI 今天做的事其實是同一種動作的兩個方向：對泰國新創是主動擴大准入，對 Cursor 是主動收回准入，兩者都不是被動發生，而是 OpenAI 自己選擇要不要繼續開放模型存取。
