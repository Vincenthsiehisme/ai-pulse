# NVIDIA 一天發三篇 Vera Rubin 公告，把 agent 工作負載包裝成新的算力剛需

> 今天的問題：NVIDIA 今天用三篇公告把 agent 工作負載描述成比一般查詢貴上 15 倍的新剛需，藉此力推 Vera Rubin NVL72 的效率數字與開放互連，這套敘事今天的材料撐得住嗎？

NVIDIA 公告 Vera Rubin NVL72 的每瓦工作量比前代最多提升 30 倍，並引用 OpenRouter 的數據：agent 型 AI 工作負載消耗的 token 量是一般單次對話的 15 倍。公告舉了一個具體情境說明原因：AI agent 做一次投資研究，要查財務資料庫、搜尋新聞與申報文件、再呼叫子 agent 去跑同業比較，一連串步驟疊加起來就是那 15 倍。

同一天，NVIDIA 另外宣布擴充 Vera Rubin NVL72 平台，加入針對 agent 工作負載最佳化的快速 token 生成能力。公告標題也提到 Groq 3 LPX 已進入全面量產，但內文摘要完全沒有說明兩者實際如何整合。

第三篇公告談的是 NVLink Fusion：NVIDIA 讓第三方 XPU（客製化 AI 加速晶片，非自家 GPU）透過 NVLink 互連進自己的系統。公告主張 AI 工廠的經濟性要看每秒 token 數、每瓦 token 數、每 token 成本、稼動率與正常運行時間這些綜合指標，而非單一顆加速器的規格。

NVIDIA 把每瓦效能推上檯面當賣點的時間點，接在整個產業為資料中心電力供應吃緊頭痛的背景之下。算力擴張撞上電網容量上限時，每瓦能做多少事，會比單純堆晶片數量更接近客戶真正在意的成本。

把 NVLink 開放給第三方 XPU 用，乍看是把自己的護城河讓出去，但更像是把競爭壓力從『買不買 NVIDIA GPU』移到『用不用 NVIDIA 的互連與系統』，後者的替代成本更高，也更難被繞過。

## 所以呢

NVIDIA 今天把 agent 工作負載塑造成比一般查詢貴上 15 倍的新剛需，用效率數字與開放互連鞏固自己在這波基礎設施升級裡的位置，但這些效率倍數目前只有官方說法，沒有獨立驗證。
