# 每日精選：怎麼挑、怎麼寫、怎麼審

> 消費者：`scripts/pulse-digest-prep.py`（本輪實作）、之後的 `pulse-digest-apply.py`
> 與 `pulse-digest-gate.py`、`scripts/selftest.py` 的判準。
> 規格先於實作（紅線 9）：這一頁先寫，碼才動。

## 這一層要解決什麼

站台現在是檔案庫，一則事件一頁。讀者要的是一篇有主線的文章——**當天的事件變成
論證裡的材料，不是各自的段落。**

2026-08-13 用 8/12 的真資料手寫過一篇（四則寫成一篇），確認做得到，
但也確認了兩件會出錯的事，這份規格就是為了擋那兩件。

## 一、寫作框架：一問三層

### 一問

一天只准有一個問題。問題要能被當天的材料**部分**回答。
串不起來就不要串，寧可只寫一則寫深。

「今天有四則」不是問題，「這筆錢憑什麼敢投一個三四年就換代的東西」才是。

### 三層

每一句話都屬於其中一層，寫的時候就標。

| 層 | 是什麼 | 要求 |
|---|---|---|
| A | 證據內（今天的 worklist 裡有） | 可以直述 |
| B | 背景知識（可查證，不在 vault） | 要標明「這是背景，今天的消息沒提」 |
| C | 作者推論 | 要明講是推論，並附一個別的解釋 |

**硬規則：結論不能只靠 B＋C 撐。**

手寫那篇就是。vault 對 NVIDIA 那則只有「六家機構、5,000 億、目標動員」一句話，
而文章裡「Brookfield 買電廠收費公路」「用二十年在算」「GPU 三四年換代」
全是寫的人從外部知識補的——**讀者分不出哪幾句有證據、哪幾句是作者說的**，
而文章好看的原因正好是那幾句。

### 反例測試

每個 C 級結論寫完問一句「有沒有別的解釋」，至少寫出一個。答不出來的不要寫。

跟變異盤點是同一件事：**變異問「把這行碼改壞，測試會不會紅」；
反例問「把這個結論反過來講，證據擋不擋得住」。**

手寫那篇的「只有一種可能：他們相信需求夠耐久」就是一條沒跑過反例的斷言
——管理費照收、offtake 擔保、債權結構、根本募不到，都是別的解釋。

## 二、選材：圖距離不是判準，是警訊

### 實測

Obsidian 的關聯圖看起來很適合回答「哪些能寫成一篇」。實際量過之後，**不適合**。

8/12 那四則兩兩配對的圖距離：

```
NVIDIA 融資 × OpenAI 企業研究     ≥4 不相連     ← 手寫那篇的骨幹
NVIDIA 融資 × MindTopo           ≥4 不相連
NVIDIA 融資 × SL2T               ≥4 不相連
SL2T × MindTopo                   2  同主線     ← 文章裡最沒話講的一對
MindTopo × OpenAI 企業研究         2  同 category
```

**圖上最近的一對，在文章裡最沒話講；圖上不相連的那一對，撐起了整篇。**

分佈也不支持。19 個有兩則以上的日子、317 組日內配對：

```
≥4 圖上不相連               187 組   59.0%
距離2 同公司                 69 組   21.8%
距離2 同主線/類別/來源/關鍵詞    61 組   19.2%
距離1 同 fingerprint          0 組    0.0%
```

拿距離當門檻，六成素材直接出局，而好文章大多在那六成裡。

### 為什麼

圖距離量的是**同題材**。同題材併起來是清單——「今天模型研究線有兩則」不是文章。

文章需要的是**張力**：兩則之間有話要說。張力最常發生在遠處，因為它需要兩個
不同的敘事位置，一個做宣稱、一個是那個宣稱的地基。

### 所以距離這樣用

| 距離 | 意思 | 用法 |
|---|---|---|
| 1（同 fingerprint） | 這根本是同一件事 | **合併成一段，不是寫成一篇**。這是去重不是編輯 |
| 2（同公司／主線／來源／關鍵詞） | 同題材 | **當警訊**：整篇素材都落在這裡，多半是清單不是論證 |
| ≥4（不相連） | 沒有共同鄰居 | **是候選，不是障礙** |

距離 1 目前幾乎沒在運作：107 則已上線事件只有 13 則有 `fingerprint`，
去重的主鍵大多是空的。

## 三、能撐起一篇的關係型別

距離不是判準，**關係**才是。能撐起一篇的只有幾種：

| 關係 | 長什麼樣 | 機器抓得到嗎 |
|---|---|---|
| 前提 | A 要成立，需要 B 為真 | ✗ |
| 矛盾 | A 與 B 對同一件事給出不同答案 | ✗ |
| **兌現／落空** | 舊事件寫過「要看 X」，新事件是不是 X | **△ 靠 `next_signal`** |
| 量尺缺口 | 一則做宣稱，另一則顯示衡量它的工具還不存在 | ✗ |
| 同鏈異位 | 同一條價值鏈的不同環節 | ✗ |

**五種裡只有第三種機器抓得到**，而它靠 `next_signal`——107 則裡大多是空的欄位。

這讓補 `next_signal` 的優先度升高：它同時是空日規則的輸入，
**也是這整套選材邏輯裡唯一的機器支點**。

其餘四種只能由人判斷。所以 prep 的輸出不是「今天最高分的 N 則」，
而是**候選組合 ＋ 每組的距離與共用屬性 ＋ 待回答的訊號清單**——
機器提供組合，人認定關係。

## 四、空日規則

過去 37 天有 15 天（41%）沒有任何事件上線。

**首選**：挑一則當初寫了「要觀察 X」、而 X 到今天還沒發生的事件，回頭檢視。
把空日變成「我們說過的話有沒有兌現」的日子。

**現況擋住這條**：`next_signal` 大多是空的。所以退而求其次用弱規則
——最高 `value` 且未曾在任何一期出現過。

不論走哪條，**空日的稿必須在開頭明說今天沒有新事件**並附監看數字，
讓讀者分得出「今天沒事」跟「今天沒跑」。

## 五、產線與人的那一關

```
pulse-digest-prep.py    確定性：挑材料、算距離、列待回答訊號 → _probe/digest-worklist.json
Cowork 寫               敘述：產出分層 JSON（A/B/C + counter + dropped）
pulse-digest-apply.py   確定性：機檢退件 → voice_clean → 寫 Digests/<date>.md
pulse-digest-gate.py    確定性：人審三格沒填完就不 render
```

`Digests/` 跟 `Events/`、`Tracks/`、`Actors/` 平行，`kind: digest`。
**不要塞進 `Events/`**：dashboard 的三桶對帳掃的是 `Events/*.md`，
混一個不同 kind 進去會讓那道守衛的語意糊掉。

### 機器擋得住的（寫成退件規則，之後那支實作）

證據層：A 級的 evidence 必須存在於當日 worklist；`so_what` 的支撐鏈至少一條 A 級；
B 級必須有 `basis`；C 級必須有 `counter`；`dropped` ∪ 被引用 ＝ worklist 全集。

語言層：封閉式推論黑名單（只有一種可能／必然／唯一的解釋）；破折號密度；
「不是 A，是 B」全篇一次；粗體詞數；設問密度；中國用語與半形標點。

### 機器擋不住的（明講，不要假裝有守）

- 這個問題值不值得問
- B 級的背景知識對不對
- **類別滑動**——手寫那篇把「視覺語言模型的拓撲推理」接到「企業 agent 可靠性」上，
  任何正則都抓不到

所以這條鏈的產出是**草稿**。人只看三件事：問題成不成立、B 級認不認同、
`counter` 誠不誠實。三格填完才 render。

### 生成語意跟 Tracks / Actors 相反

那兩種每次重新生成。**Digest 生成一次就不能再被覆寫**——不然審過的稿隔天被改掉，
而沒有人會發現。那正是 2026-08-12 潤稿鏈的形狀，
所以 apply 要帶跟 `pulse-enrich-apply.py` 同一道拒寫守衛。
