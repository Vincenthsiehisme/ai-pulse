## 事實
Amazon 在 Hugging Face 的部落格發布文章，說明如何把 Strands Agents（Amazon 自家的開源 agent 框架）、LeRobot（Hugging Face 的機器人學習函式庫）與 Hugging Face Storage Buckets 接在一起，讓機器人資料的錄製、訓練、部署走同一條資料流程。語料只給了標題與一句制式摘要，沒有更多技術細節或具體案例。

## 證據
- [[Sources/src-hf-blog|src-hf-blog]] — Record, train, and deploy from one place with Strands Agents, LeRobot, and Hugging Face Storage Buckets（https://huggingface.co/blog/amazon/strands-lerobot-streaming-data-loop）

## 脈絡
LeRobot 是 Hugging Face 這兩年主推的開源機器人學習專案，目標是把模仿學習、強化學習用同一套工具鏈處理；Strands Agents 則是 Amazon 今年釋出的 model-agnostic agent 開發框架。這篇文章把兩個各自獨立的開源專案接上 HF 的雲端儲存服務，屬於工具鏈整合而非新產品發表。
