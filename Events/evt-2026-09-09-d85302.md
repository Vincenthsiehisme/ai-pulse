## 事實
vLLM 專案在 GitHub 發布 v0.29.0，release notes 顯示這個版本來自 277 位貢獻者（91 位新加入）的 594 個 commit。重點變動是「Model Runner V2」正式成為所有模型的預設執行路徑，完成了先前從 pooling 模型開始的推行；MRV2 同時新增了 CUDA graph 記憶體剖析功能，用於 KV cache 的自動調校。

## 證據
- [[Sources/src-gh-vllm-releases|src-gh-vllm-releases]] — v0.29.0（https://github.com/vllm-project/vllm/releases/tag/v0.29.0）

## 脈絡
vLLM 是目前開源 LLM 推論引擎裡採用度最高的專案之一，核心賣點是用 PagedAttention 提升推論吞吐量。Model Runner 是它內部負責實際執行模型前向計算的元件，V2 版的推行從去年的 pooling 模型開始逐步擴大，這次是收尾成為全面預設。

## 影響
貢獻者結構（277 人、91 位新面孔）顯示這個專案的開發社群還在擴大，不是少數核心維護者在支撐。CUDA graph 記憶體剖析對 KV cache 自動調校的意義，是讓部署端不用再手動猜測顯存配置參數，直接降低調校門檻，對中小型團隊自建推論服務的門檻是實質降低。

## 判斷
這是一次例行的大版本更新，不是突破性的能力發表，但「V2 成為預設」代表這個新執行路徑已經過了足夠的實戰驗證期，社群對它的穩定性有信心。開源推論引擎的版本節奏本身就是基礎設施成本下降的一個持續性訊號，不需要單則過度解讀。

## 下一個訊號
留意下一個大版本是否會移除舊版 Model Runner 的相容層，那會是 V2 遷移真正完成的訊號。
