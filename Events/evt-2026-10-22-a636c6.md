## 事實
依 Simon Willison 引述，Anthropic 宣布把 Agent Skills 標準捐給 Linux 基金會旗下的 Agentic AI Foundation（AAIF），Anthropic 是該基金會的共同創辦者之一，聲明稱要讓 Agent Skills 保持開放、由社群驅動且不綁定單一廠商。Anthropic 官方公告我們只保留標題與連結，原文：https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation 。

## 脈絡
Agent Skills 是讓代理載入技能與指令的格式。捐給中立基金會，意味治理權不再只在 Anthropic 手上。

## 影響
其他廠商採用這套格式的顧慮會降低。治理結構與投票權細節（證據不足，待補）。

## 判斷
這是標準之爭中常見的一步：把格式交給中立組織，換取更廣的採用。是否真的拉到競爭對手，要看後續。

## 下一個訊號
OpenAI、Google 等是否宣布支援 Agent Skills，或加入 AAIF 相關工作組。
