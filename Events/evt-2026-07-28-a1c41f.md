## 事實
OpenAI 發布一份 field report，記錄科學家用 AI coding agent 改造既有科學計算軟體，並宣稱在基因體學等領域加速了軟體開發與研究發現。

## 證據
- [[Sources/src-openai-blog|src-openai-blog]] — Scientific computing in the age of agentic AI（https://openai.com/index/scientific-computing-agentic-ai）

## 脈絡
agentic coding 從一般軟體工程往科研軟體延伸，而科研軟體多半是老舊、少人維護的 legacy code，正是 agent 補位的縫。這是 OpenAI 把 coding agent 推進科研場景的案例敘事。

## 影響
若案例屬實，指向 coding agent 在專業科研軟體現代化上的落地。但這是 OpenAI 自家 field report，樣本、方法、加速幅度都未揭露，實際效果證據不足。

## 判斷
單一來源、自家報告。案例方向可信，但缺獨立佐證與可量化成果，記為落地訊號而非已驗證的成效。
