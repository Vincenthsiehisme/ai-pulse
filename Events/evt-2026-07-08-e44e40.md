## 事實
NVIDIA 表示 Nemotron 3 Ultra 在 LangChain 的 Deep Agents harness 上拿到領先的 benchmark，並主打成本低於頂級閉源模型；LangChain 為此調校了 Deep Agents。

## 證據
- [[Sources/src-nvidia-blog|src-nvidia-blog]] — NVIDIA Nemotron Achieves Benchmark-Leading Performance With LangChain Deep Agents Harness（https://blogs.nvidia.com/blog/nemotron-langchain-agents-open-stack/）

## 脈絡
開放權重模型近一年主打的就是「接近閉源、成本更低」。這次多了一個具體場景，跟 LangChain 這個被廣泛採用的 agent 編排平台綁在一起測。

## 影響
對想自建 agent 的團隊，這是一組「開放模型加主流編排框架」的成本論證。但 benchmark 是 NVIDIA 給的、跑在特定 harness 上，跨場景能不能複現才是重點。
