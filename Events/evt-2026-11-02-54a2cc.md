## 事實
OpenAI 官方部落格介紹 Qodo 與 Codex 的整合：Qodo 把公司內部知識與程式碼規範帶進 Codex，讓開發者在開 pull request 之前，就能跨多個程式庫抓出 P0 等級的問題。外掛的安裝方式、價格與涵蓋的語言，來源摘要沒寫（證據不足，待補）。

## 證據
- [[Sources/src-openai-blog|src-openai-blog]] — Qodo builds context into AI code review with Codex（https://openai.com/index/qodo-codex-plugin）

## 脈絡
AI 程式碼審查的瓶頸之一是模型不知道各團隊自己的規範與歷史決策。Qodo 這類工具的賣點是補上這層組織脈絡，Codex 則是 OpenAI 的程式代理產品。

## 影響
這是 Codex 生態系擴充第三方外掛的一個例子，審查動作前移到開 PR 之前。實際抓出問題的準確率沒有公布數字。
