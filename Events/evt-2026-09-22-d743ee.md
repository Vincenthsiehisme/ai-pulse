## 事實
vLLM 專案在 GitHub 發布 v0.30.0，release notes 顯示這個版本來自 315 位貢獻者（104 位新加入）的 762 個 commit。重點變動包括新增對 DeepSeek-V4.1-Flash 的支援，這個模型的 KV cache 全部改用 MXFP8 格式儲存，透過 FlashMLA V4.1 在 SM100（NVIDIA Blackwell 架構）上創下紀錄；另外還有 DeepGEMM Mega-mHC 與非同步 Engram 預取機制，細節在摘要中斷處之後我們沒有取得。

## 證據
- [[Sources/src-gh-vllm-releases|src-gh-vllm-releases]] — v0.30.0（https://github.com/vllm-project/vllm/releases/tag/v0.30.0）

## 脈絡
vLLM 是目前開源 LLM 推論引擎裡採用度最高的專案之一，這次版本更新的重心明顯放在支援最新一代 DeepSeek 模型與新硬體架構（SM100／Blackwell）的搭配優化，而不是通用功能擴充。

## 影響
貢獻者規模（315 人、104 位新面孔）持續擴大，顯示這個專案的開發社群仍在成長；KV cache 用 MXFP8 儲存若真能維持精度並降低顯存占用，對部署 DeepSeek 大型模型的團隊會直接反映在硬體成本上。

## 判斷
這個版本把重心放在盡快接住 DeepSeek 最新模型，而不是自己開發新功能，反映出開源推論引擎生態跟著模型廠商的發布節奏在追，誰家模型話題度高，社群資源就往哪裡集中。

## 下一個訊號
觀察 MXFP8 儲存 KV cache 在實際部署中的精度損失是否可接受，以及 DeepGEMM Mega-mHC 與 Engram 預取機制的具體效能數字何時公布。
