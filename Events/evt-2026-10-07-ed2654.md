## 事實
微軟研究院部落格發表 Agent Lightning v1.0。摘要說明：agent 的工具、上下文與決策由複雜框架管理，用強化學習訓練不容易；Agent Lightning 把既有的 agent 接上 RL 訓練，不必重寫就能改進。標題寫明框架約 3,500 行，並強調能搭配真實的 harness 訓練。效果數據證據沒有提供（證據不足，待補）。

## 證據
- [[Sources/src-msr-blog|src-msr-blog]] — Agent Lightning v1.0: A 3,500-Line Lightweight Agentic RL Framework for Training Agents with Real Harnesses（https://www.microsoft.com/en-us/research/blog/agent-lightning-v1-0-a-3500-line-lightweight-agentic-rl-framework-for-training-agents-with-real-harnesses/）

## 脈絡
agent 的 RL 訓練難在 agent 本身包在各種框架裡，訓練程式要跟著改。這個框架的取向是從外面接上去，而不是替換 agent。

## 影響
若接入成本確實很低，現有 agent 做 RL 的門檻會下降。實際改善幅度，證據沒有數字。

## 判斷
3,500 行這個數字是賣點，也是可以直接驗證的部分，程式碼放出來就看得到。至於「不用重寫」是否在複雜 agent 上也成立，要看實際接入的例子。

## 下一個訊號
v1.0 的程式碼庫與接入範例，以及第三方在非微軟 agent 框架上的訓練報告。
