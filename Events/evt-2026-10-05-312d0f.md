## 事實
vLLM 專案發布 v0.31.0，包含 717 個 commit、307 位貢獻者，其中 96 位是第一次貢獻。Highlights 第一項是 DeepSeek-V4.1-Flash 的效能：FlashMLA mega attention 搭配 V4.1 的 NVFP4 壓縮 KV cache，成為 SM100 的預設路徑（#56935）；indexer 改用 DeepGEMM 的 sparse MQA logits（#56254）。其餘亮點在證據摘要被截斷，這裡不補。

## 證據
- [[Sources/src-gh-vllm-releases|src-gh-vllm-releases]] — v0.31.0（https://github.com/vllm-project/vllm/releases/tag/v0.31.0）

## 脈絡
vLLM 是開源的 LLM 推論引擎，新模型的支援速度與 kernel 優化常直接反映在這類 release note 裡。這一版的第一條亮點就針對單一模型（DeepSeek-V4.1-Flash）與特定硬體世代（SM100）。

## 影響
預設路徑改成 NVFP4 壓縮 KV cache，對在 SM100 上跑這個模型的人，記憶體佔用與吞吐會直接受影響。具體幅度證據裡沒有數字（證據不足，待補）。

## 判斷
這一版把 DeepSeek-V4.1-Flash 當成第一優先處理，代表推論引擎端已經把這個模型視為需要專屬優化的主流部署對象。但 release note 只列出改動、沒給 benchmark，實際收益要等第三方量測。

## 下一個訊號
vLLM 或社群是否公布 DeepSeek-V4.1-Flash 在 SM100 上、新舊預設路徑的吞吐與延遲對照。
