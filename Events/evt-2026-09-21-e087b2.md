## 事實
OpenAI 部落格案例指出，客戶 V7 使用 GPT-5.6，把原本散落在各處的公司檔案轉換成 AI agent 可以取用的脈絡資訊，讓 agent 能完成複雜、且可回溯來源的工作。證據摘要只有這一句話，沒有提供具體導入規模、行業別或成效數字。

## 證據
- [[Sources/src-openai-blog|src-openai-blog]] — How V7 gives AI agents institutional memory（https://openai.com/index/v7）

## 脈絡
「給 agent 制度性記憶」處理的是企業導入 AI agent 常見的痛點——agent 缺乏跨對話、跨任務的持久知識，只能靠使用者每次重新提供脈絡；V7 的做法屬於這條「agent 記憶層」解法之一。

## 影響
若這套方法真的有效，能降低企業導入 agent 時的脈絡建置成本，讓 agent 的輸出更貼近公司實際知識而非只靠模型的通用知識；但缺乏具體量化數字，實際效果只能參考。
