## 事實
OpenAI 宣布 ChatGPT Enterprise 可透過 AWS Marketplace 購買，企業能沿用既有的 AWS 採購與計費關係。

## 證據
- [[Sources/src-openai-blog|src-openai-blog]] — ChatGPT Enterprise now available in AWS Marketplace（https://openai.com/index/chatgpt-enterprise-aws-marketplace）

## 脈絡
大企業的 AI 採購常卡在新增供應商流程，雲端市集可以直接動用既有的雲端承諾額度。

## 影響
採購門檻降低，也讓 OpenAI 的企業版進入 AWS 通路，與 AWS 自家的模型服務同台。

## 判斷
這是通路動作，不是產品能力變化；價格是否與直購相同、能否抵用 AWS 承諾額度，摘要沒寫（證據不足，待補）。
