## 事實
Images 2.6 的更新包含更快的圖像生成、GIF 製作、更精準的編輯，以及新的 API 控制項，涵蓋 ChatGPT、Codex 與 API 三個入口。

## 證據

## 脈絡
圖像能力同時進到 ChatGPT、Codex 和 API，表示它不只是聊天介面的功能，開發者也能直接呼叫。

## 影響
API 新增控制項對做產品的人比較實際，GIF 與精準編輯則偏向終端使用者。摘要沒有提供速度數字或價格。
