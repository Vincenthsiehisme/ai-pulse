## 事實
OpenAI 說明打開兩個 API 設定，保留推理（retaining reasoning）與啟用壓縮（compaction），讓 GPT-5.6 在 ARC-AGI-3 這個 benchmark 的分數翻了三倍，同時提升效率。

## 證據
- [[Sources/src-openai-blog|src-openai-blog]] — How enabling two settings tripled our scores on the ARC-AGI-3 benchmark（https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores）

## 脈絡
ARC-AGI-3 是衡量抽象推理的 benchmark，GPT-5.6 是 OpenAI 的新模型。這篇是 OpenAI 教人怎麼調設定把分數拉高。

## 影響
「三倍」聽起來大，但它來自兩個設定開關，不是模型本身變強：同一顆模型換個用法就翻三倍，說明這個分數對 API 設定很敏感。對讀跑分的人是提醒，看到 ARC-AGI-3 數字要先問是哪組設定跑的。

## 判斷
分數是 OpenAI 自報，缺第三方複現。三倍是真的還是設定調出來的，要別人用同樣設定跑一次才算數。

## 下一個訊號
看有沒有獨立第三方用同組設定在 ARC-AGI-3 上複現這個三倍。
