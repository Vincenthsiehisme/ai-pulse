## 事實
Perplexity 的 Portable Computer 正式在 Windows 上線，是其 agent 產品 Perplexity Computer 的本機版本，靠 NVIDIA RTX GPU 加速跑本機模型，讓多步驟任務的規劃與執行留在裝置端。

## 證據
- [[Sources/src-nvidia-blog|src-nvidia-blog]] — Perplexity Portable Computer Is Now Available on Windows, Powered by NVIDIA RTX（https://blogs.nvidia.com/blog/local-ai-perplexity-windows-pcs/）

## 脈絡
Perplexity Computer 原本是雲端執行的 agent，負責規劃並執行多步驟任務。Portable Computer 是把這套能力搬到本機執行的版本，隨著本機模型能力提升，敏感資料也不必離開裝置。

## 影響
把 agent 能力放上消費級 RTX 顯卡，等於把「本機跑 agent」的門檻壓低到一般 Windows PC 就能碰到。對 NVIDIA 是本機 AI PC 的賣點敘事，對 Perplexity 則多了一個不吃雲端運算成本的部署選項。

## 判斷
這則是由 NVIDIA 部落格發布的通路與平台合作公告，重點在「上了 Windows、有 RTX 加速」這個分發動作，不是新模型或新能力本身。

## 下一個訊號
留意本機版實際跑的是哪顆模型，以及跟雲端版 Perplexity Computer 在任務完成率上差多少，這會決定本機版是閹割版還是真正堪用的替代品。
